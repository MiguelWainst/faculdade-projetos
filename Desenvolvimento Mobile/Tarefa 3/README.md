# Supervisão de Máquinas — Tarefa 3

Protótipo Flutter para supervisão de máquinas industriais.

## Recursos implementados

- Portal de acesso com validação e navegação.
- Dashboard com seis sensores em `GridView.builder`.
- Histórico com 50 ocorrências em `ListView.builder`.
- Carregamento simulado de 2 segundos, reconhecimento de alarmes e filtro de gravidade assíncrono.
- Tema, modelos e componentes reutilizáveis organizados em `lib`.

## Execução

```bash
flutter pub get
flutter run
```
